# 小东鸭｜杭州东站具身智能服务机器人

小东鸭是一个「AI 产品经理 × 具身智能 × 机器人产品」作品集项目，探索如何把线上 AI 智能体的理解能力，延伸为能够在真实物理空间完成任务的机器人服务系统。

## 我的角色

AI 产品经理。主要负责语音交互、一键传唤、自动距离汇合、机器人导航、异常兜底，以及多机器人运营后台的产品设计。

## 项目解决的问题

真实机器人服务不仅要理解用户，还必须同时处理位置、状态、任务、硬件、网络、空间安全和异常。项目将这些约束组织为可观测、可调度、可干预的完整服务链路。

## 互动 Demo

包含运营驾驶舱、机器人管理、任务调度、内容管理、空间安全、告警中心和实时态势大屏。任务演示遵循最新规则：机器人和用户距离不大于 10 米时自动判定汇合成功，不使用预约码。

## 本地运行

```bash
npm install
npm run dev
npm run build
```
